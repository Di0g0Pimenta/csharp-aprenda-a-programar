# Aprenda a Programar com C#

Exercícios e exemplos de estudo baseados no livro
**"Aprenda a Programar com C#"**, de António Trigo e Jorge Henriques.

## Estrutura

Cada capítulo possui duas pastas:

- `Exemplos/` — exemplos apresentados no livro.
- `Exercicios/` — exercícios realizados durante o estudo.
